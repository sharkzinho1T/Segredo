# Para Rebecca 💜

Site estático feito com HTML, CSS e JavaScript. Funciona no GitHub Pages e pode ser personalizado pelo Android.

## Personalizar pelo celular

1. Abra `index.html` para alterar os textos da carta.
2. A linha do tempo já está configurada com os três momentos e horários informados: 03/11 às 18:11, 05/11 às 22:14 e 13/11 às 23:05.
3. Coloque três imagens na pasta `assets` com estes nomes exatos:
   - `foto-1.jpg`
   - `foto-2.jpg`
   - `foto-3.jpg`
4. Opcional: coloque uma música que você tenha direito de usar em `assets/musica.mp3`. A música só começa quando a pessoa toca no botão, por causa das regras dos navegadores.
5. Edite a carta para que o pedido de desculpas seja verdadeiro e específico ao que aconteceu.

## Publicar no GitHub Pages

1. No GitHub, crie um repositório público, por exemplo `para-rebecca`.
2. Envie `index.html`, `style.css`, `script.js` e a pasta `assets` para a raiz do repositório.
3. No repositório, entre em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`, depois toque em **Save**.
6. Aguarde alguns minutos. O GitHub mostrará o endereço público do site na mesma tela.

## Observações

- Não precisa de servidor, banco de dados, Node.js ou root.
- O Google Fonts precisa de internet; se estiver offline, o site usa fontes alternativas.
- As fotos e o arquivo de música precisam ser adicionados por você. Os espaços de foto mostram um marcador até isso acontecer.
- Não coloque informações privadas, conversas pessoais ou fotos que Rebecca não queira tornar públicas. Um repositório público deixa os arquivos acessíveis a qualquer pessoa com o link.
